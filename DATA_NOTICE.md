# Dataset notice

`synthetic_loans.csv` is **synthetic demo data generated for this portfolio project** with a fixed random seed. It is not real LendingClub borrower data and must not be described as such. The columns are inspired by commonly used LendingClub-style loan fields, but the records and outcomes are simulated. Use it to run the app and test the workflow.

For an empirical LendingClub analysis, download an appropriate historical dataset from a source you are permitted to use, review its license/terms and data dictionary, map its columns to the documented schema, and rerun the pipeline. Do not commit raw borrower-level data to a public repository unless the dataset's terms clearly permit it.
